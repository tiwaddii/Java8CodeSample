# ☕ Java 8 Feature Practice Repository

This repository contains **hands-on coding examples and practice programs** based on **Java 8 features**.
It is designed to help developers understand and apply modern Java concepts used in real-world applications.

---

## 🚀 Features Covered

* 🔹 Lambda Expressions
* 🔹 Functional Interfaces
* 🔹 Stream API
* 🔹 Method References
* 🔹 Optional Class
* 🔹 Default & Static Methods in Interfaces
* 🔹 Date and Time API (java.time)
* 🔹 Collections Enhancements

---

Each files contains **well-structured examples** with clear implementations.

---

## 🧠 Purpose

* Practice and strengthen **Java 8 concepts**
* Prepare for **technical interviews**
* Understand **real-time usage of streams and functional programming**

---

## 🛠️ Technologies Used

* Java 8
* Eclipse IDE
* Git & GitHub

---

## ▶️ How to Run

1. Clone the repository:

```
git clone https://github.com/tiwaddii/Java8CodeSample.git
```

2. Import into IDE (Eclipse/IntelliJ)

3. Run any class with `main()` method

## 📌 Sample Topics Implemented

* Filtering and mapping using Streams
* Sorting using Lambda expressions
* Finding duplicates in collections
